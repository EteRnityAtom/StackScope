Scoped reconnaissance for authorized testing

Use an origin-relative path. Page routes stay at this path or below it. Same-origin scripts and API endpoints referenced by those pages may use paths elsewhere on the same origin.

Enter exact origins only, separated by commas. Firefox will request access for each one. Only JavaScript and source maps are fetched from these hosts; page routes and API checks remain on the active origin.

Map a bare import prefix to an origin-relative script path, separated by semicolons. Import maps in the page are read automatically.

Use exact origin-relative prefixes for app-specific API routes that do not contain words such as api, graphql, or v1. Requests remain on the active origin.

Only enable this for hostnames and paths explicitly allowed by the bug-bounty scope. It sends bounded same-origin GET requests with credentials omitted, records status/metadata only, and does not save response bodies. GET can still have side effects.

The cap applies to page, endpoint, and script requests together. Raise it for larger apps; pages stay in the selected module path, while supporting scripts and APIs stay on the active origin.

There is no link or JavaScript recursion-depth cutoff. The URL budget, total-time deadline, and server rate-limit responses keep the scan bounded.

After selecting a module path above, start this observer, close the popup, and click through the app. It records same-origin method, redacted URL, status, duration, selected response-header metadata, and supported request parameter names. It never stores or sends parameter values or response bodies, and does not replay requests.

Opt-in sends one same-origin GET without cookies for each unique eligible GET your page makes, up to 1,000 requests. It skips credential-like URLs and state-changing route names. GET can still have side effects; non-GET methods are observed but never replayed.

Use only for an authorized assessment. Normal requests ask Firefox to include same-origin browser credentials; StackScope never reads or exports cookie/token values. Apps using bearer tokens in local storage may not have an authenticated baseline. Anonymous GET comparison runs only when you opt in above. No exploit payloads are sent, and GET requests can still have side effects.
